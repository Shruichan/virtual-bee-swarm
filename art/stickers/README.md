# Bee Scout sticker sheets

These two 1536 × 1024, indexed-color PNG sheets use the supplied `beedraw1.png` bee as their character reference. Each has transparency and six outlined sticker illustrations:

- `bee-expressions-sheet.png` — wave, curiosity, sleep, flower-carry, flower crown, and happy hover.
- `bee-field-guide-sheet.png` — wildflowers, magnifying glass, pebble water dish, garden, spray-free blossom, and flower-shape comparison.

The bee keeps the source drawing's golden body, chocolate stripe, brown antennae, pink-white wings, and sparkling eyes. No new text was added, so each sticker stays clean at small sizes.
